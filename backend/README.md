# 📝 Todo App Backend API

FastAPI-based intelligent Todo application backend with AI chatbot capabilities.

## 🚀 Features
- Task Management (CRUD)
- User Authentication (JWT)
- AI Chat Assistant
- Real-time Notifications
- Recurring Tasks
- WebSocket Support

## 📡 Live API Endpoints
- Health Check: \/health\
- API Documentation: \/docs\
- Alternative Docs: \/redoc\

## 🔧 Tech Stack
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication
- WebSockets
